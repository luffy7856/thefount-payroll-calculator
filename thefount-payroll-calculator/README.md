# 더파운트 병의원 인건비 계산기

2026년 기준 실수령액·총 지급액을 병원 총 인건비로 환산하는 반응형 계산기입니다.

## 포함 기능

- 실수령액 ↔ 세전 급여 역산
- 국민연금, 건강보험, 장기요양보험, 고용보험, 산재보험
- 사업주 부담금과 퇴직금 월 적립액
- 공제대상 가족·8~20세 자녀 반영
- 두루누리 지원 예상액
- 연장·야간·휴일수당 및 5인 미만 사업장
- 식대·보육수당·자가운전보조금 비과세
- 재직기간 월·연간·전체 누적 인건비 시뮬레이션
- 직원별 계약 방식을 혼합할 수 있는 팀 인건비 합산
- 두루누리 지원 및 병의원 네트제 계약 가이드
- 개원 초기비용·운전자금·자금출처별 대출 상환 및 이자 계산

## 배포

### Vercel

이 폴더를 GitHub 저장소에 올리고 Vercel에서 Import하면 `vercel.json` 설정으로 배포됩니다.

### Cloudflare Workers/Pages

프로젝트를 GitHub에 올린 뒤 Cloudflare에서 연결하고 빌드 명령을 `pnpm run build`로 설정합니다. Node.js 22 이상을 사용하세요.

## 로컬 확인

```bash
pnpm install
pnpm run dev
```

계산 검산은 `pnpm run verify`로 실행할 수 있습니다. 대표 4개 급여 사례가 참고 사이트 결과와 8원 이내인지 자동 확인합니다.

> 본 계산기는 참고용입니다. 실제 신고와 급여 지급 전 세무사 또는 노무사 확인을 권장합니다.
